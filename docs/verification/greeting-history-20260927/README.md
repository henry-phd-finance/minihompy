# 인삿말 HISTORY와 댓글 줄간격 (2026-09-27)

HISTORY에서 인삿말 변경 기록을 공개 조회한다. 최초 배포는 현재 인삿말만 시작 기록으로 보존하며, 과거 수정 시각을 추정하지 않는다. 이후 인삿말 내용이 바뀐 성공한 설정 저장만 DB trigger가 기록한다. 사진·메뉴·제목 변경이나 같은 내용 재저장, CAS 충돌은 기록을 추가하지 않는다.

주인만 항목을 확인 후 삭제할 수 있다. 삭제는 현재 인삿말/설정/사진을 수정하지 않는다. 직접 insert/update는 공개 계정에 허용하지 않으며, delete는 개인 관리자 RLS를 적용한다. 최신순 10개씩 조회하고 빈 값/빈 목록/조회 오류·재시도와 삭제 응답 유실을 처리한다. 계정 변경·메뉴 이탈 시 창과 이전 권한을 폐기한다.

사진첩·다이어리 등 공통 photo-comment 본문 줄 높이는 1.2, 행 아래 margin은 0으로 조정한다. 글자 크기는 유지한다.

- SQL: `202609270004_home_greeting_history.sql`. 기존 SQL은 수정하지 않는다. 전체 신규 install과 friend-visibility prepare에 포함.
- 로컬 검증: DB 실제 RLS/trigger/저장 충돌/실패/삭제 격리, 1280/375px 공개 조회·페이지·주인 삭제/취소/응답 유실·텍스트 삽입 안전성·계정/메뉴 전환, 설치 재실행/신규 전체 SQL, Pages build/artifact.
- 실제 운영에서는 인삿말을 변경하거나 이력을 삭제하는 테스트를 하지 않는다. 저장·삭제는 격리 테스트에서 검증하고 운영은 기존 설정 보존과 시작 기록·공개 조회를 검사한다.

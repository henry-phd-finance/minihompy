# 홈 일촌평 디자인 — 2026-09-26

참고: https://m.blog.naver.com/PostView.naver?isHttpsRedirect=true&blogId=tigerprinting&logNo=220495281297 의 일촌평 캡처 (`cy일촌.png`).

- `Friends say` 대신 `일촌평` 제목. 회색 띠 안의 제목·한 줄 높이 입력칸·확인 버튼. 제목 폭은 내용만큼 사용하고 입력칸이 남은 폭을 채운다.
- 본문, 괄호 안 작성자 링크, 회색 날짜를 한 흐름으로 배치하고 얇은 구분선 적용. 긴 글/기존 줄바꿈은 안전하게 줄바꿈한다.
- 평상시 로그인/작성권한/빈 목록 안내 및 수동 새로고침 제거. 작성 가능한 일촌에게만 입력칸 표시. 실패 때만 짧은 오류와 다시 시도 표시. 처리 결과 불명확 시 결과 조회/동일 작업 재시도 기능 유지.
- 성공 메시지는 스크린리더 안내로 유지하고 시각적으로 숨김. 화면 재진입과 창 포커스 복귀 시 목록/권한 자동 갱신. 창 복귀 시 이전 중앙 조회 오류도 재확인.
- 삭제 권한, 중복 작성 방지, 세션 갱신, 메뉴 이탈 시 초안 폐기는 유지.

## 검증

`verify-friend-reviews-ui.mjs`: Chromium → 실제 중앙/개인 handler → PGlite SQL, 1280/375px 14개 그룹 통과. 정상 화면에 상시 새로고침 없음, 한 줄 제목/입력 배치, 빈 목록, 작성/삭제/페이지 이동, 비활성 작성자와 최신 링크, 만료 갱신 중 초안, 응답 유실 복구/동일 요청 재전송, 일촌 해제, 목록 오류와 키보드 재시도, 중앙 장애 중 관리자 삭제, 메뉴 이탈/계정 전환 확인. 결과 ui.log.

실제 A/B 공개 홈에서 정상 시 상시 안내/새로고침이 없는지 확인하고 배포된 세 파일 해시 대조. 입력 가능 상태 및 저장 검증은 위 로컬 실제 API/SQL 테스트에서 수행하며 운영 데이터 쓰기는 하지 않음. 스크린샷 `/tmp/friend-reviews-design/`.

# 홈 새 글 N 표시 — 2026-09-26

홈의 메뉴별 게시물 숫자 바로 뒤에 작은 주황색 사각형과 흰색 N을 표시한다. 기존 권한별 서버 집계의 `counts[kind].today > 0`일 때만 표시하며 한국 시간 기준 오늘 새 글을 의미한다. 방문자별 읽음 여부는 사용하지 않는다. 메뉴의 활성화 여부·순서와 권한별 집계는 기존 로직을 유지한다.

- 변경: `home-activity.js`, `styles.css`, `scripts/verify-home-activity.mjs`.
- 1280px/375px 실제 브라우저 fixture 검증 6개 그룹 통과: 양수/0개 혼합, 전체 0개, 메뉴 숨김/순서 변경, 새로고침, 오류/재시도, 수명 만료, 키보드 이동.
- PC/모바일 스크린샷을 직접 확인. 기존 화면 크기/레이아웃 유지.
- A/B 배포·실제 공개 홈 검증은 인접 JSON 파일 참조. DB/Edge 함수 변경 없음.

참고: 사용자가 제공한 2010년 싸이월드 홈 화면의 메뉴별 숫자 뒤 주황색 N. 스크린샷은 `/tmp/home-new-badge/home-1280.png`, `home-375.png`, `A-hosted.png`, `B-hosted.png`에 저장.
